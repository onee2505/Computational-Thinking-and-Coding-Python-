

# Computational Thinking and Coding (Bachelor: SEM1) 30 credit

## This module develops the core computational thinking and coding skills essential for systematic problem-solving. 

Learning Outcomes:
1) Analyse and use appropriate data structures and algorithms to solve real world problems from a toolbox of techniques.

2) Develop solutions to complex problems by decomposing them into smaller more manageable sub problems.

3) Identify difficulties associated with machine intelligence related tasks that we may wish to program a computer to solve.
